### 7.1 System Architecture Design

复用真实 AS、PS 和 Worker 路径及原 Fake ChatModel 和 CONFIG 定义。AS 测试子进程只在此套件开启既有 V15 及固定路由。

### 7.2 High-Level Design

先核验五仓、制品、三个隔离库和 AS V15 空表。两租户分别正常完成 Process、Agent、Outbox、Inbox 和 Worker 业务效果。按 PS 持久派发得到精确 AS run ID，再用 AS 只读 observer 验证事实。

### 7.3 Detailed Design

现有 Fake 流式 Adapter 输出 10 输入、5 输出和 15 总数。原 V2 settlement 为 USD 0.05。精确 Fake route/model 的每百万单位 tariff 3000/4000 由原 V15 算法计算为 USD 0.05。

源查询要求 tenant、SERVICE issuer/subject、关联、原生 BPMN instance 和注册 source 对应已完成 AS Run。V2 和 V15 按 tenant/run/reservation 精确连接，最多两行以拒绝重复。检查 MODEL、SETTLED、PRICED、价格版本、租约 epoch、金额、计数、共同结算时刻和最终摘要。
