### 7.1 System Architecture Design

保持现有 S07 固定 Agent Tool、AS USER 与出站 Process SERVICE 责任。独立 suite 复用原子进程启动和隔离数据。

### 7.2 High-Level Design

每个租户首条完成 Run 使用原 USER 专用 READ，读取从序号 0 到精确终态水位的既有 SSE。核对原 V13 调用、V2 结算和 native Process START；保持原回放与外租户拒绝断言，随后互换两个首条 Run 的 SSE 并要求相同 404 语义。

### 7.3 Detailed Design

SDK 仅等真实 stream.complete。夹具限制 64 个事件和十秒，始终取消 subscription。检查所有事件 runId 与连续顺序。两个 Tool 事件须有唯一 invocation UUID、准确 key/version/hash、同 correlation、闭集字段及 REQUESTED/0、SUCCEEDED/1/SETTLED。拒绝任何附加 Tool 帧或附加字段。

既有 V13 调用、action intent 和 V2 结算从原 AS owner 查询；以原 S07 观察者确证 Process native START 回执。按实际 tenant、SERVICE 受信 issuer/subject、目标资源、命令摘要及精确实例重算 Tool receipt 参考摘要。跨租户 SSE 要求 404 TIANJI_RESOURCE_NOT_FOUND。每个生产端继续负责自己的鉴权。
